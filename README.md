# Motorola edge 50s pro でライト常時点灯しながら写真撮影する方法

## 概要
Open Camera を使うことで、ライトを常時点灯したまま起動および撮影が可能なことを確認。

## 動作確認した環境
- Motorola edge 50s pro
- Android バージョン：○○

## 手順
1. Google Play から **Open Camera** をインストール
2. 起動後、設定（歯車アイコン）を開く
3. フラッシュ設定を **Torch（懐中電灯）** に設定
4. ライトが常時点灯したまま写真撮影可能
